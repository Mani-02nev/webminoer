## 🎓 Admin Dashboard Quick Guide

### Access
- **URL:** `https://your-domain.com/admin`
- **Password:** `mani02112007`

### Common Tasks

#### Send Certificate to One Person
1. Login to admin panel
2. Click "Attendance" tab
3. Find the person in the list
4. Click "Send Cert" button
5. Certificate is generated and emailed

#### Send Certificates to Everyone
1. Login to admin panel
2. Click "Attendance" tab
3. Click "Send Certificates to ALL" button
4. Confirm the action
5. Wait for progress bar to complete

#### Create Manual Certificate
1. Login to admin panel
2. Click "Manual" tab
3. Enter: Name, Email, Date
4. Click "Generate & Send"
5. Download PDF or send email

#### Resend Registration Email
1. Login to admin panel
2. Click "Registered Users" tab
3. Find the person
4. Click email icon
5. Confirm resend
